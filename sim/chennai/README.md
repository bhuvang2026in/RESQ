# Thousand Lights SUMO network

This SUMO scenario is a visual prototype, separate from the web demonstration.
It runs random background traffic and one ambulance from the approximate
Nungambakkam start point to Apollo Hospitals on Greams Road. The ambulance route
is generated by the repository's Dijkstra router using free-flow SUMO edge travel
times. SUMO's static traffic-light programs run in the network; the ambulance
does not yet request green lights through ResQ/TraCI.

The generated network is intentionally not committed because OpenStreetMap data
changes and the exact junction corrections must remain reviewable. After installing
SUMO and setting `SUMO_HOME`, run:

```powershell
.\.venv\Scripts\python.exe sim\chennai\build_network.py
sumo-gui -c sim\chennai\chennai.sumocfg
```

The network builder also creates `generated/landscape.poly.xml`,
`generated/ambulance.rou.xml`, and `generated/scenario.add.xml`. OSM buildings,
parks, and land-use areas use the palette in `landscape.typ.xml` to provide map
detail behind darker roads. The scenario file labels the approximate ambulance
start and Apollo Hospitals destination and draws the planned route in green.
Vehicles use SUMO's constant-size-when-zoomed-out mode, so they remain visible at
overview scale and return to road scale as you zoom in. SUMO displays each traffic
light's current indication and advances its guessed static cycle while the
simulation runs. The signal timings are generated estimates and have not been
field-verified.

The checked-in bounding box is the project starting point around Apollo Hospitals,
Greams Road. Before collecting final results, inspect every signal, one-way, turn
restriction, and the Gemini flyover in `sumo-gui`; store corrections as plain-XML
patches rather than editing the generated `.net.xml` directly.

Generated files are placed under `sim/chennai/generated/` and ignored by Git.
